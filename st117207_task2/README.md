# Состояния космического аппарата Shuttle (вариант 18) — задание 2

Выполнил: студент группы st117207 Белобородов Д. А.

Классификация состояний радиаторной системы космического аппарата Shuttle
по девяти числовым показаниям бортовых датчиков (набор UCI Statlog Shuttle).
Сравниваются базовая модель, логистическая регрессия, kNN, SVM с RBF-ядром,
решающее дерево, случайный лес и HistGradientBoosting. Основная метрика —
macro-F1, поскольку класс 1 занимает около 80 % данных.

## Сборка одной командой

```bash
pip install -r requirements.txt
python build.py            # данные → модели → report.pdf (в корне проекта)
python build.py tables     # пересобрать таблицы и макросы без переобучения
python build.py clean      # удалить производные файлы LaTeX, таблицы и рисунки
```

Сборка требует:

* Python 3.11+ и пакеты из `requirements.txt`;
* LaTeX с `pdflatex` (MiKTeX или TeX Live) — компиляция отчёта по ГОСТ 7.32-2017;
* 7-Zip (`7z.exe` в PATH или `C:\Program Files\7-Zip\7z.exe`) — только если
  исходные данные нужно распаковывать заново (`shuttle.trn` в архиве UCI
  сжат в `.Z`). В поставке проекта данные уже распакованы.

## Методика (кратко)

* **Данные** — 58 000 записей, 9 числовых признаков A--I, 7 классов.
  Использовано разбиение авторов набора: 43 500 записей обучения и
  14 500 теста. Тест открывается один раз, после выбора модели.
* **Признаки** — все девять показаний без ручного конструирования.
  Физический смысл признаков в описании набора не раскрыт; первый признак
  документирован как «время», но порядок строк перемешан, поэтому время
  как порядок утрачено.
* **Предобработка** — `StandardScaler` внутри `Pipeline` для логистической
  регрессии, kNN и SVM. Для дерева, леса и бустинга масштабирование не
  используется; отдельно проверено, что оно не меняет результат.
* **Подбор** — `GridSearchCV` и `RandomizedSearchCV` только по обучающей
  части, стратифицированная пятикратная кросс-валидация, метрика macro-F1.
* **Эксперименты** — переобучение дерева (глубина, минимальный лист),
  зависимость леса от числа деревьев и `random_state`, кривые бустинга
  при двух `learning_rate`, влияние трёх гиперпараметров леса и бустинга.
* **Оценка** — accuracy, сбалансированная accuracy, macro/weighted-F1,
  ROC-AUC one-vs-rest, матрицы ошибок всех моделей, F1 по классам,
  перестановочная важность и коэффициенты логистической регрессии.
* **Воспроизводимость** — все случайные процессы с `random_state = 42`;
  все числа в отчёте генерируются из `data/processed/results.json`.

## Главный исследовательский результат

При accuracy выше 99 % macro-F1 может быть заметно ниже, потому что
macro-F1 усредняет классы равноправно, а классы 2, 3, 6 и 7 представлены
единицами или десятками объектов. У kNN accuracy 99,91 % сочетается
с macro-F1 87,65 %, у SVM — 99,76 % и 84,42 %, у логистической регрессии —
95,39 % и 82,14 %. Одна ошибка на редком классе меняет его F1 на десятки
процентов, но почти не влияет на accuracy. Оценки для классов 6 и 7
(4 и 2 тестовых примера) статистически ненадёжны.
