## Сборка одной командой

```bash
pip install -r requirements.txt
python build.py            # данные → признаки → модели → report.pdf (в корне проекта)
python build.py clean      # удалить производные файлы LaTeX, таблицы и рисунки
```

Сборка требует:

* Python 3.11+ и пакеты из `requirements.txt`;
* LaTeX с `pdflatex` (MiKTeX или TeX Live) — компиляция отчёта по ГОСТ 7.32-2017;
* 7-Zip (`7z.exe` в PATH или `C:\Program Files\7-Zip\7z.exe`) — распаковка `.7z`/`.rar`
  исходных данных (резервный путь — пакет `py7zr` для внутреннего архива).

## Методика (кратко)

* **Цель** — `rul_h`: время от текущей записи до конца данного испытания
  (по отметкам времени в именах файлов), ч.
* **Признаки на запись** (по каждому подшипнику): RMS, дисперсия, эксцесс,
  пик-фактор и доли энергии в пяти широких полосах (0–1, 1–2, 2–3, 3–5, 5–10 кГц).
  Амплитудные признаки нормируются на здоровый базовый уровень (медиана первых 10 %
  записей испытания) и логарифмируются; время записи и номер записи признаками
  не используются.
* **Агрегаты** — конфигурация А «по подшипникам» (36 признаков) и конфигурация
  Б «худший подшипник» (9 признаков, поэлементный максимум).
* **Физическая постановка** — цель `min(RUL, C)` с порогом C, подобранным по КВ
  (плато исправного состояния).
* **Разбиение** — только временное: испытание 1 полностью в обучении,
  испытание 2 полностью отложено; гиперпараметры — `GridSearchCV` с
  `TimeSeriesSplit(5)` только по испытанию 1; тест используется один раз.
* **Область применимости** — признаки ограничиваются диапазоном обучения
  (`RangeClipper`), модель не экстраполирует.
* Воспроизводимость: все случайные процессы с `random_state = 42`.

## Воспроизводимость

Все числа в отчёте (`\input`-макросы и таблицы) генерируются автоматически из
`data/processed/results.json`; ручное редактирование чисел в `report.tex` не требуется.
Пересборка таблиц без переобучения: `python src/modeling.py tables`.
